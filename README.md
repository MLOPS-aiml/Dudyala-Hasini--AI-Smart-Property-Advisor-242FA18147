# AI Smart Property Advisor

AI Smart Property Advisor is an intelligent machine learning-based system that analyzes property characteristics and provides data-driven property price predictions and personalized recommendations. The system helps users make informed property decisions by combining machine learning, data analysis, and an interactive application.

## Features

- Property price prediction
- Intelligent property recommendations
- Property feature analysis
- Data preprocessing and cleaning
- Exploratory data analysis
- Machine learning model training and evaluation
- Model serialization using Joblib
- Interactive user interface
- Data-driven property insights

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- Joblib

## Machine Learning Workflow

1. Load the property dataset.
2. Clean and preprocess the data.
3. Perform exploratory data analysis.
4. Select relevant features.
5. Split the data into training and testing sets.
6. Train machine learning models.
7. Evaluate model performance.
8. Select and save the best-performing model.
9. Use the trained model for property price prediction.
10. Generate personalized property recommendations.

## Installation

Clone the repository:

    git clone https://github.com/MLOPS-aiml/AI-Smart-Property-Advisor.git

Navigate to the project directory:

    cd AI-Smart-Property-Advisor

Install the required dependencies:

    pip install -r requirements.txt

## Run the Application

    streamlit run app.py

## Model Deployment

The trained machine learning model is stored using Joblib and loaded by the application for making predictions on new property information.
